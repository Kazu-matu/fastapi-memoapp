### 7-2. 実行環境要件

| 項目 | 要件 |
| --- | --- |
| 実行環境 | Python 3.12 以上が動作するサーバー |
| OS | Linux（Ubuntu 22.04 以上推奨）または Windows Server 2022 以上 |
| メモリ | 512MB 以上（推奨 1GB） |
| ディスク | 1GB 以上（データ増加を考慮し余裕を持って） |
| ネットワーク | 社内 LAN からのみアクセス可（外部公開不要） |
| ポート | 8000（または情報部門指定のポート） |

### 7-3. データベース

| 項目 | 内容 |
| --- | --- |
| DB 種別 | PostgreSQL 15 以上 |
| DB 名 | `{app_name}_db`（変更可） |
| ユーザー名 | `{app_name}_user`（変更可） |
| 接続方式 | asyncpg（非同期ドライバ） |
| 初期化 | 初回のみ `python init_database.py` の実行が必要 |
| バックアップ | 情報部門の標準バックアップポリシーに従ってください |

### 7-4. 環境変数（`.env` ファイル設定値）

> セキュリティのため、`.env` ファイルはリポジトリに含まれていません。
> サーバー上で以下の値を設定してください。

| キー | 説明 | 設定例 |
| --- | --- | --- |
| `APP_NAME` | アプリ表示名 | `{アプリ名}` |
| `DEBUG` | デバッグモード | `false`（本番は必ず false） |
| `DATABASE_URL` | PostgreSQL 接続文字列 | `postgresql+asyncpg://user:pass@host:5432/db` |

### 7-5. アプリケーション起動コマンド

```bash
# パッケージインストール（初回・更新時）
uv sync --extra prod

# DB 初期化（初回のみ。既存データが消えるため本番では注意）
uv run python init_database.py

# 起動コマンド（本番）
uv run uvicorn main:app --host 0.0.0.0 --port 8000 --workers 2

# systemd サービスとして登録する場合は上記コマンドを ExecStart に設定してください
```
