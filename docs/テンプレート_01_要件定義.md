## 4. 機能要件

### 4-1. 主要機能一覧

| 機能ID | 機能名 | 概要 | 優先度 |
| --- | --- | --- | --- |
| F-01 | データ登録 | フォームから新規データを登録する | 必須 |
| F-02 | データ一覧表示 | 登録データを一覧で表示する | 必須 |
| F-03 | データ編集 | 登録済みデータを修正する | 必須 |
| F-04 | データ削除 | 登録済みデータを論理削除する | 必須 |
| F-05 | 変更履歴表示 | データの変更履歴を確認する | 推奨 |
| F-06 | （追加機能） | （説明） | 任意 |

### 4-2. 機能詳細

#### F-01. データ登録

- **入力項目:**
  - （例: タイトル）: 必須、最大 XX 文字
  - （例: 内容）: 任意、最大 XX 文字
  - （例: カテゴリ）: 選択式、〇〇・〇〇・〇〇
- **処理内容:**
  - バリデーション後に DB に保存する
  - 登録者・登録日時を自動記録する
  - 変更履歴（CREATE）を自動記録する
- **完了後の動作:**
  - 一覧画面にリダイレクト（PRG パターン）
  - 「登録しました」メッセージを表示

#### F-02. データ一覧表示

- **表示項目:**
  - ID、タイトル、（その他項目）、登録日時、操作ボタン
- **ソート:**
  - デフォルト: 登録日時の降順
- **フィルタ:**
  - （例: 未完了のみ表示）
  - （例: キーワード検索）

#### F-03. データ編集

- **遷移:** 一覧の「編集」ボタン → 編集フォーム
- **処理:** バリデーション後に DB を更新、変更履歴（UPDATE）を記録
- **完了後:** 一覧画面へリダイレクト

#### F-04. データ削除

- **方式:** 論理削除（`is_deleted = True`）。DB からは消えない
- **確認:** 削除前に確認ダイアログを表示する
- **処理:** 変更履歴（DELETE）を記録
- **完了後:** 一覧画面へリダイレクト

## 9. 制約・前提条件

- 開発言語: Python 3.12 以上
- Web フレームワーク: FastAPI + Jinja2（SSR）
- DB: 開発環境は SQLite、本番は PostgreSQL（情報部門が管理）
- パッケージ管理: uv
- 本番サーバーは情報部門が用意・管理する
- 認証機能は今回のスコープ外（社内 VPN 内限定アクセスで代替）
