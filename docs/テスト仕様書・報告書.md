# テスト仕様書・報告書

## 1. テスト概要

| 項目 | 内容 |
| --- | --- |
| 対象システム | メモアプリ（FastAPI + Jinja2） |
| テスト種別 | 単体テスト / 結合テスト / E2E テスト |
| テストフレームワーク | pytest（単体・結合） / Playwright（E2E） |
| テスト DB | インメモリ SQLite（`:memory:`）—本番コードの DB とは独立 |

---

## 2. テスト構成

```text
tests/
├── conftest.py            # 共通フィクスチャ（インメモリ DB・テストクライアント）
├── unit/
│   └── test_schemas.py    # スキーマ（Pydantic）のバリデーション
├── integration/
│   └── test_api.py        # API エンドポイントの結合テスト
└── e2e/
    └── test_memo_app.py   # Playwright による E2E テスト
```

### conftest.py の概要

- `test_engine`: インメモリ SQLite エンジン（テスト間で DB を共有しない）
- `setup_db` フィクスチャ: テスト関数ごとにテーブルを CREATE / DROP
- `client` フィクスチャ: `app.dependency_overrides` でテスト用 DB セッションに差し替え

## 7. 不具合一覧

テスト実施中に検出した不具合（修正済み含む）。

| 不具合 ID | 検出テスト | 概要 | 重要度 | 状態 |
| --- | --- | --- | --- | --- |
| BUG-01 | E2E-03 | `frontapp/app.js` で `due_date` が未設定のとき空文字列 `""` を送信し、API が 422 エラーを返す | 高 | **修正済み** |
| BUG-02 | IT-01〜IT-13 | リファクタ後に API パスが `/memos/` → `/api/memos/` へ変更されたが、テストコードが旧パスのままで全件 307 リダイレクト | 高 | **修正済み** |
| BUG-03 | IT-01 | POST 正常登録のレスポンスが `200` → `201` に変更されたが、テストが `200` を期待していた | 中 | **修正済み** |

### BUG-02 詳細

- **発生箇所**: `tests/integration/test_api.py`
- **原因**: リファクタで API プレフィックスを `/api/memos` に変更したが、テストの `BASE = "/memos"` を更新していなかった。
- **修正内容**: `BASE = "/api/memos"` に変更。

### BUG-03 詳細

- **発生箇所**: `routers/memo.py`、`tests/integration/test_api.py`
- **原因**: REST 標準に従い新規登録を `201 Created` に変更したが、テストが `200` を期待したまま。
- **修正内容**: `test_create_memo_success` の `assert res.status_code == 201` に修正。
